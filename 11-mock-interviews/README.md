## System Design Mock Format

```
00:00 – 05:00   Clarify requirements (you ask questions)
05:00 – 10:00   Estimate scale, define constraints
10:00 – 25:00   High-level design (draw + narrate)
25:00 – 40:00   Deep dive on 2 components (interviewer picks)
40:00 – 50:00   Trade-offs, failure modes, scaling, cost
50:00 – 55:00   Back-and-forth questions
```
