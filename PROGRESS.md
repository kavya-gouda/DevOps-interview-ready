## How Sessions Work

1. You say **"good morning"**
2. Copilot reads this file, finds your position, and presents **the next scenario**
3. For each scenario:
   - Copilot presents the question / problem
   - You answer (written, spoken, or think it through)
   - Copilot evaluates, fills gaps, and adds depth
   - You say **"next"** to advance, or ask to **"go deeper"**
4. You say **"done for today"** to end the session
5. Copilot tells you to update your position in this file

### Session Commands
| You say | What happens |
|---|---|
| `good morning` | Start or resume session |
| `next` | Move to the next scenario |
| `go deeper` | Copilot dives deeper into current topic |
| `hint` | Copilot gives a hint without giving the answer |
| `skip` | Skip current scenario (logged as skipped) |
| `repeat` | Copilot re-asks the current scenario fresh |
| `done for today` | End session, Copilot summarises what to update |
| `switch to [topic]` | Jump to a different topic file |
| `test me` | Copilot asks questions without showing the scenario text (pure recall) |
